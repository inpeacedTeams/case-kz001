# case-kz001

Одностраничный кейс-дек. Вертикальный свайп на всю высоту экрана, без зависимостей, весь CSS и JS внутри `index.html`.

## Что внутри

17 экранов: сводка, три субъекта, разбор госномера, карта маршрута, арифметика по ИИН, выводы с уровнями уверенности, пробелы и план на 8 пунктов.

- `scroll-snap` по вертикали, `100dvh`, safe-area под вырез
- граф связей живым SVG: тап по узлу раскрывает описание
- лайтбокс на скриншоты, открывает уже загруженный файл без повторной сети
- чеклист с сохранением в `localStorage`
- стрелки и PageUp/PageDown на десктопе

## Картинки

Три скриншота лежат в `img/` в формате WebP и подключены относительными путями с явными `width`/`height`, чтобы браузер держал место под них и вёрстка не прыгала. Если файла нет, на его месте появляется подпись с именем, вёрстка остаётся целой. Имена и размеры в [`img/README.md`](img/README.md).

## Локально

Открыть `index.html` в браузере. Сборка не нужна.

## GitHub Pages

Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`. Бесплатный тариф отдаёт Pages только с публичного репозитория.

В `<head>` стоит `noindex, nofollow, noarchive`. Это просьба к поисковикам, а не защита: страница по ссылке открыта всем.
