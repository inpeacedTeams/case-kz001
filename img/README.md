# img

Сюда положить три файла ровно с такими именами:

| Файл | Размер | Что на нём |
|---|---|---|
| `desktop.webp` | 1400×788 | Рабочий стол: терминал с полями, профиль Instagram, пикселизованное фото |
| `ok.webp` | 1400×1160 | Профиль в Одноклассниках, сетка из 42 друзей, два обведены |
| `map.webp` | 1400×933 | Карта коридора Беруний → Ургенч → Бейнеу → Актау |

## Как конвертировать

Открой [squoosh.app](https://squoosh.app), закинь PNG, выбери WebP, качество 80, ширину 1400. Из 2 МБ выйдет 150–300 КБ, и на скриншотах с текстом разницы не видно.

Ширина и высота прописаны в `index.html` атрибутами `width` и `height`, чтобы браузер зарезервировал место заранее и вёрстка не дёргалась при загрузке. Если пропорции твоих файлов отличаются, поправь числа в HTML под фактические, иначе по краям появятся тонкие полосы.

Пока файлов нет, на слайдах вместо картинки стоит подпись с именем недостающего. Вёрстка остаётся целой.
